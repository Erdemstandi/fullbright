### **Changeable Key**
With changeable key you can change the toggle key according to your preference  
the default button is set to "B"

### **Language Support**
With language support, the toggle outputs and the keybinds menu will fit way better to your game  
the most used languages are supported.

### **Light-weight**
With light-weight there will not be any performance loss

### **Client-side**
With client-side the mod will work everywhere without any problem

### **Pure Fabric**
With pure fabric, no API will be required
